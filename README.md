# era760-ToolBox

Minecraft Bedrock Edition のアドオン開発を、もっと簡単にするためのツール集です。

## Inspiration

このプロジェクトは、Minecraft Bedrock Edition のアドオン制作を支援する
「とかさん ToolBox」にインスパイアされて作成されました。

Manifest Generatorなど、アドオン制作を簡単にする便利なツールを提供していた
とかさん ToolBoxの考え方に影響を受けています。

## Goal

Minecraft Add-on開発で発生する面倒な作業を減らし、
初心者でも気軽にアドオン制作を始められる環境を目指します。
